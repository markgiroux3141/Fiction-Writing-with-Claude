# Texts — Manifest

53 text files plus 5 source PDFs, ~23 MB. Everything in `canon/`, `gulf-south/`,
`weird-pulp/`, `craft-essays/` and `period/` is public domain and was downloaded from
Project Gutenberg unless noted. `additional/` is different — see that section.
Filenames are `author__title`.

These are here so a draft can check a period usage, a scene shape or a sentence rhythm
against a real source in seconds rather than from memory. **Read a story, not the
whole volume.** Annotations on what each one is for live in
`../influences/reading-map.md`.

## Adding to this folder

1. Plain text (`.txt`) or markdown (`.md`), UTF-8.
2. Filename `author-surname__short-title`, lower case, hyphens.
3. Right subfolder; create a new one if none fits.
4. Add a row here, with what the volume actually contains — the tables above were
   built by grepping the files, not by trusting the titles, and that is why the
   Stevenson and Amelia Edwards entries say what they say.
5. If it closes an entry in `../00-ACCESS-GAPS.md`, strike it there.
